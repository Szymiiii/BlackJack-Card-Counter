# Blackjack Engine & Simulator 🃏

System w języku Python tworzony przy pomocy AI przeznaczony do gry w Blackjacka, zawierający interaktywny tryb 1v1, symulator masowy do analizy statystycznej oraz moduły wizji komputerowej w trakcie przygotowania.

---

# 🛠️ Aktualne Moduły

Repozytorium zawiera obecnie dwa główne skrypty:

* **`blackjack_engine_1v1.py`** – Interaktywna gra w Blackjacka 1v1 przeciwko krupierowi w czasie rzeczywistym. Obsługuje pełną logikę zasad kasynowych, dynamiczne zliczanie Asa (1 lub 11) oraz weryfikację wygranych.
* **`SymBlackjack1v1.py`** – Automatyczny symulator wielokrotnych rozgrywek 1v1, służący do przeprowadzania symulacji masowych i analizy statystycznej (wskaźniki wygranych, zachowanie strategii przy dużej liczbie prób).
